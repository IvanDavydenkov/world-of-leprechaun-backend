# Свои VPN-конфиги в личном кабинете

## Why
Пользователю нужен список своих конфигов и скачивание выбранного файла. Доступ к чужим конфигам запрещён.

## What Changes
- GET /me/configs — JSON-массив только собственных активных конфигов.
- GET /me/configs/{config_id}/download — скачивание собственного активного конфига как .conf.
- Владелец определяется исключительно по действующей сессии; клиент не выбирает user_id.
- Проверка владельца и состояния выполняется VPN-сервисом перед чтением зашифрованного файла.

## Impact
Публичные маршруты users, доверенные внутренние маршруты vpn-configs, существующий FileVault и сценарий Download. Потребуется безопасная передача бинарного ответа и Content-Disposition между сервисами. Чтения чужой базы сервисом не допускаются.

## Approval
ОДОБРЕНО пользователем. Реализованы список и скачивание только собственных активных конфигов, проверка сессии и межсервисной идентичности, выдача .conf из зашифрованного хранилища. Тесты доступа и HTTP-контракта проходят.

## Out of Scope
Выдача, удаление и реактивация пользователем, административное скачивание чужих файлов, vpn://, трафик, импорт неназначенных peer.
