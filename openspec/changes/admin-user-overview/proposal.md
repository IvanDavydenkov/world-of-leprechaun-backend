# Список пользователей со сводкой VPN

## Why
Администратору нужен единый список зарегистрированных пользователей, их конфигов и суммарного потребления VPN-трафика для личного кабинета.

## What Changes
Расширяется существующий GET /admin/users. Успешный ответ остаётся JSON-массивом пользователей. Для каждого пользователя возвращаются профиль, число активных/отключённых/ожидающих конфигов, массив конфигов и накопленный трафик.

Подтверждено пользователем:
- трафик за всё время, входящий плюс исходящий;
- учитываются удалённые конфиги и прежние выдачи после повторной активации;
- нужны счётчики и массив конфигов с детализацией;
- отключённый конфиг — подтверждённый deleted, отдельной паузы нет.
- существующие peer могут не иметь владельца; они учитываются отдельно до назначения;
- при назначении пользователю переносится весь доступный накопленный расход конфига, включая период без владельца.

## Capabilities
### New Capabilities
- admin-user-overview: защищённый массив пользователей с VPN-сводкой и историей расхода.

## Impact
users отвечает за профиль и проверку текущей роли; vpn-configs отвечает за метаданные, поколения выдач, сбор и хранение счётчиков трафика. Нужны внутренний пакетный API статистики, доверенное межсервисное соединение и фоновый сбор показаний AmneziaWG по SSH. Чужие базы сервисы не читают.

Изменение зависит от текущего admin-config-management. Оно не выдаёт конфиги, не реализует паузу и не меняет согласованный жизненный цикл.

Уточнение области: добавить обнаружение неназначенных peer и их назначение пользователю без перевыпуска. Импорт сам по себе не меняет VPN-доступ. Историю до импорта учитываем в объёме доступных серверных счётчиков и сохранённых показаний; утраченные данные не восстанавливаем вымышленными значениями. Само назначение не делает приватный клиентский файл доступным, если он отсутствует.

## Approval
Статус: ЧЕРНОВИК ДЛЯ ОДОБРЕНИЯ. Реализацию не начинать до явного одобрения пользователя.

На одобрение:
- поля профиля: id, yandex_id, display_name, role, created_at;
- пагинация существующего endpoint: limit=50, максимум 100, after; весь каталог доступен последовательным чтением страниц;
- обновление трафика раз в 60 секунд, stale после 120 секунд для незавершённых выдач;
- при недоступности vpn-configs возвращать пользователей с VPN-данными unavailable, а не подменять неизвестное нулём;
- трафик — наблюдаемый расход peer AmneziaWG, не счёт хостинг-провайдера; период до начала учёта либо утраченные при сбое показания отмечаются как неполные.

## Out of Scope
Тарифы и биллинг, периоды/графики расхода, онлайн-статус и последний handshake, email/аватар/новые OAuth scopes, пауза, трафик Xray, экспорт всех пользователей отдельным файлом. Количество пользователей не ограничивается размером одной страницы.
