## 3. Проверка
- [ ] Пароль не сохраняется открытым и не попадает в ответы/логи.
- [ ] Unknown/mismatched SSH key отклоняется, чужие роли не управляют серверами.
- [ ] Смена default не перенаправляет старые операции и отзывы.
- [ ] Сбой target сохраняет прежний файл; повторы не создают дубликаты.
- [ ] Недоступный source не блокирует выдачу, но не даёт ложного статуса отзыва.
- [ ] Deleted/pending не переносятся; гонки с удалением/revoke-all безопасны.
- [ ] Сбой после создания peer до переключения восстанавливается без утечки действующего peer.
- [ ] История и ID конфигов сохраняются, статистика не удваивается.
- [ ] Импорт повторяемый и не меняет реальные peer/файлы.
- [ ] Проверить миграцию в изолированной среде; реальные выдачи/отзывы выполнять только в согласованной области.
