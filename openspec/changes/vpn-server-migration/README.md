# Передача на реализацию: переключение VPN-серверов

Актуальная модель согласована 2026-11-02: старые выдачи продолжают работать до ЯВНОГО отзыва администратора; возврат на сервер использует сохранённые ключи. Подготовка/helper выполняются через сайт. VPS и Amnezia устанавливаются вручную.

Начать агенту фронтенда:
1. frontend-handoff.md — сценарии экрана, polling, ошибки и приёмка.
2. api-contract.md — целевые endpoints и DTO с примерами.
3. design.md — инварианты backend и гонки/границы модели.
4. specs/vpn-server-management/spec.md — нормативные требования.
5. tasks.md — что ещё предстоит реализовать и проверить.

Статус: спецификация готова для передачи. Backend реализован локально и проверен Go/HTTP/SSH/Python/MongoDB/CLI тестами. Новые маршруты требуют выкладки нового backend и одноразового импорта существующих env/выдач; инструкция docs/vpn-server-switching.md. Production и frontend ещё не обновлены. Старый текст одноразовой миграции заменён. Не реализовывать автоматический отзыв source/revoke-old или обязательную новую выдачу при возвращении на действующий сервер.

Область изменений: frontend admin UI + backend/schema/worker/SSH helper + одноразовый переход существующих env/выдач на server bindings. Этот пакет не выполняет production-переключение сам. Действующие peer и файлы при подготовке спецификации не менялись.
